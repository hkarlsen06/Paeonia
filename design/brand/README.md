# Paeonia Brand Assets

Canonical brand delivery from the logo designer.

## Files

```text
design/brand/
├── originals/
│   ├── print/   # Designer PDF exports
│   └── source/  # Editable AI/EPS source files
├── previews/    # JPG review mockups and previews
└── web/         # SVG/PNG web exports
```

## Variants

- `58860_Paeonia_RM-01`: full brand lockup with symbol, wordmark, and tagline. Use for marketing surfaces where text is appropriate.
- `58860_Paeonia_RM-02`: app-icon mark. Use as the source for app icon work, favicons, and compact brand placements.

## App Icon Pipeline

The app-icon source SVG is also copied to:

```text
design/app-icon/source/concepts/paeonia-app-icon-mark.svg
```

The PNG beside it is only a preview. Final app icon assets should be exported from vector/source artwork, then composed in Apple Icon Composer.

## Ignored Delivery Files

The download also included `.DS_Store` and `Thumbs.db`. These are operating system metadata files created by macOS and Windows file browsers. They do not contain logo artwork and should not be committed.
