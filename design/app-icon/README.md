# Paeonia app icon

Canonical source artwork for the Paeonia app icon.

## Pipeline

Design the icon as flat, opaque, vector layers without the iOS rounded-rectangle mask. Export separate SVG layers for Icon Composer, and tune material, depth and appearance there. Export PNGs only for review, marketing or fallback.

## Direction

The selected concept is the delivered RM-02 app-icon mark, copied to `source/concepts/paeonia-app-icon-mark.svg`. It should feel intimate and premium without becoming childish or generic.

## Source files

`source/concepts/paeonia-app-icon-mark.svg` is the delivered SVG with the plum background. The `-content` variants drop the background, `-content-tight` crops to the mark, and `-content-tight-square` sits on a tighter square canvas. Prefer the last for Icon Composer if the non-square crop behaves awkwardly.

Design constraints:

- recognizable at small sizes
- no literal flower illustration
- no text
- no initials unless the mark earns it
- strong silhouette
- works in light, dark, tinted, and clear icon appearances
- emotional read: private, together, warm, resilient
